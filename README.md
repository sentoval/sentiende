# Sentiende + SeFinancia

Motor **Sentiende** (`codigo/sentiende`, `codigo/app`) y variante **SeFinancia** (`codigo/variantes/sefinancia`, solo configuración).

- Cada cambio en `main` crea `SeFinancia.exe` en Windows (GitHub Actions) y lo publica en **Releases** como `SeFinancia_v1.1_windows.zip`.
- Para crearlo en tu propio equipo: doble clic en `Crear_SeFinancia.bat` (ver `LEEME.txt`).
- Guía del código: `codigo/LEEME.md`.
